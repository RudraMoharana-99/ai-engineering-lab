# Model-card worksheet

Teaching model: [HuggingFaceTB/SmolLM2-135M-Instruct](https://huggingface.co/HuggingFaceTB/SmolLM2-135M-Instruct).

The card describes a compact instruction-tuned model in the 135M size class and lists an Apache-2.0 license. We chose its scale for a small mechanics exercise, not as a recommendation for high-quality production answers. The script records the actual parameter count and immutable revision.
